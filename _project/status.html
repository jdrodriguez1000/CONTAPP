Palabras que usamos

Fase 0
El entendimiento: antes de construir, se acuerda qué es la app, para quién y sus reglas.
Slice
Un pedazo de la app que ya sirve de punta a punta. El proyecto tiene 6.
Lote
Un grupo de pocos pasos de una slice que cabe en una sesión.
Paso (P-X)
Una tarea pequeña del plan, por ejemplo P-7 "letras de otros idiomas no entran".
Ronda
Cada vuelta al coder para corregir lo que encontraron las revisiones.
Rojo / verde
Rojo: la prueba falla porque falta el código. Verde: ya pasa.
CI
GitHub corre todas las pruebas solo en cada cambio que se sube.
Mantenimiento (MANT)
Un lote pequeño fuera de las slices para ajustar herramientas o pagar deuda, por ejemplo MANT-001.
